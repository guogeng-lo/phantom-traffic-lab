# Phantom Traffic Lab：幽靈塞車

沒有紅燈、沒有事故、沒有施工，車流還是會自己塞住，而且塞車波會往後跑。這個專案把相關研究整理成一份可以追溯出處的LLM Wiki，再用它做一份讀者可以自己操作的教學HTML簡報。

**目前進度：剛建立，正在讀第一批文獻。**簡報還沒有做。

## 這個專案在做什麼

- **Wiki：**每篇文獻記錄實際讀到哪裡，每個主張一張證據卡，標明是論文裡的實驗、論文裡的模型，還是我們自己推導或模擬的結果。
- **簡報：**讀者自己點車子踩煞車、看塞車波怎麼往後傳、調整條件看車流什麼時候會變不穩定。每頁都可以展開「出處」，看到對應的證據卡和檢查結果。
- **流程：**從Wiki到簡報分成8個節點，程式檢查和AI審查分開，錯了就退回出問題的那一關。設計在`.agents/workflows/graph.md`，每次執行的紀錄在`runs/`。

## 資料夾

| 位置 | 內容 |
|---|---|
| `wiki/` | 文獻、證據卡、術語表、研究差異、簡報對照表，從`wiki/index.md`開始看 |
| `pipeline/` | 需求摘要、教學大綱、逐頁稿 |
| `runs/` | 每次執行的檢查紀錄，包括失敗的 |
| `audition/` | 選題階段的模型驗證（不是正式流程） |
| `scripts/`、`tests/` | 檢查程式和它的測試 |
| `AGENTS.md` | 給AI的規則 |

## 怎麼跑檢查

需要Python 3，只用標準函式庫。

```
python3 scripts/check_wiki.py       # 檢查文獻、證據卡、索引，並掃描個資和金鑰
python3 tests/test_check_wiki.py    # 故意弄壞資料，確認檢查程式擋得住
```

選題階段的模型測試怎麼跑，見`audition/README.md`。
