## 共同設定

| 項目 | 設定 |
|---|---|
| 模型 | `dv_n/dt = a[V(h_n) − v_n] + f_n(t)`，`V(h) = tanh(h − 2) + tanh2`（Bando式(1)、(24)），無因次 |
| 道路 | 環狀道路，環長L，N台車。第n台的前車是第n+1台，最後一台的前車是第0台 |
| 位置 | 程式內部用不取餘數的累積位置，車距`h_n = x_{n+1} − x_n`（最後一台加L）。畫圖時才對L取餘數 |
| 積分 | RK4，時間步長`dt = 0.05` |
| 均勻車流 | 車距`b = L/N`，每台車速度`V(b)` |
| 煞車 `f_n(t)` | 被點的那台車，在`[t0, t0 + τ]`這段時間加上固定的減速`−β`；其他時間和其他車都是0。寫在微分方程式裡，跟RK4一起積分，不是每一步之後硬改速度 |
| 「幾乎停住」 | 車速 < 0.1（Bando圖7、8塞車團裡的車速約0.03） |
| 「有塞車」 | 有任何一台車的車速 < 0.1 |
| 「看起來均勻」 | 所有車的速度跟`V(b)`差不到0.01 |
| 擾動大小 `A(t)` | 所有車的`|v_n − V(b)|`取最大值 |
| k=1的波 | 車距偏差投影到k=1：`|Σ_n (h_n − b) e^{−i2πn/N}| / N` |

**共同的物理檢查S**，每一個模擬都要通過，否則那一項直接算失敗：
- S1：任何時刻所有車距 > 0（沒有撞車或超車）。
- S2：任何時刻所有車速 ≥ −1e−9（沒有倒車）。
- S3：所有車距加起來等於L，誤差 ≤ 1e−9。

理論成長率σ：用Bando式(10)，`z² + az − aV'(b)(e^{iα} − 1) = 0`，取實部最大的根。

## M1：22台、車距2的分界a（第5頁）

- **設定**：N = 22、L = 44、k=1的小擾動。
  - 位置加上`10^−6·cos(2πn/N)`，速度不動。
- **量法**：
  - 成長率`σ_meas`：對`ln(k=1的波)`在時間區間`[100, T_end]`做線性回歸的斜率。
  - `T_end` = 2100，或k=1的波第一次超過10^−3的時間，取比較早的。
  - 分界`a_meas`：在a ∈ [1.90, 2.00]用二分法找`σ_meas`變號的地方，找到區間寬度 ≤ 10^−5為止。
- **通過**：
  - `|a_meas − 1.959493| ≤ 5×10^−4`（公式`V'(2)(1 + cos(2π/22))`）。
  - **分界附近**：a ∈ {1.90, 1.94, 1.95, 1.97, 1.98, 2.00, 2.20}，每一個都要：
    - `σ_meas`跟理論σ同號
    - `|σ_meas − σ| ≤ 2×10^−5 + 0.02|σ|`
  - 理論σ參考值：
    - a = 1.94：+3.75e−4
    - a = 1.98：−3.88e−4
    - a = 2.00：−7.60e−4
  - 全程通過S。

## M2：環長44、a = 1，掃車數（第6頁）

- **設定**：L = 44、a = 1，N從3到60每一個整數。擾動和量法同M1。
- **通過**：
  - 每一個N的`σ_meas`都跟理論σ同號，而且`|σ_meas − σ| ≤ 2×10^−5 + 0.02|σ|`。
  - `σ_meas > 0`的N剛好是16～39（理論預測，使用者也用公式核對過）。
  - 分界附近的理論σ：
    - N = 15：−3.95e−3
    - N = 16：+5.54e−3
    - N = 39：+4.5e−5
    - N = 40：−1.88e−4
  - N = 39的σ很小，是這一項最難的地方，也照同樣的標準判。
  - 全程通過S。

## M3：44台的均勻速度（第6頁）

- **設定**：N = 44、L = 44（車距1）、a = 1。
- **通過**：
  - 不加擾動跑到t = 1000，所有車速跟`V(1) = 0.2024334241`差 ≤ 10^−9。
  - 加M1的k=1小擾動，`σ_meas`為負，而且跟理論σ = −6.93e−4的差在M1的容許誤差內。

## M4：第1頁的初始偏移

- **設定**：N = 22、L = 44、a = 1，均勻車流。第0台車往前偏ε，ε ∈ {0.01, 0.05, 0.1, 0.2}，跑到t = 1000。
- **記錄**：每個ε第一次「有塞車」的時間`t_jam`。
- **通過**：
  - ε = 0.1（Bando的設定）在t = 1000內形成塞車。
  - 每個ε都通過S。
- **選第1頁用的ε**：
  - 先看Bando的0.1：`t_jam`落在[60, 300]就用0.1。
  - 不在這個範圍，就在其他ε裡選`t_jam`落在[60, 300]的最大值。
  - 都不在範圍內，就照實記錄，交給使用者。
- **時間的說明**：`t_jam`是模型的無因次時間，不是秒。畫面播放多快，是逐頁製作時另外決定的顯示設定，要在畫面上寫明「動畫已加速」。

## M5：第2頁的煞車

### M5a 沒點的時候

- **設定**：N = 22、L = 44、a = 1，完全均勻，不加任何擾動，跑到t = 3000。
- **通過**：t ≤ 600之內一直「看起來均勻」。
- **記錄**：浮點誤差第一次讓車流不再「看起來均勻」的時間（如果在3000以內）。

### M5b 點一下

- **設定**：同M5a。在t0 = 20點第0台車，煞車組合β ∈ {0.25, 0.5, 1.0} × τ ∈ {0.5, 1.0, 2.0}，跑到t = 600。
- **記錄**：
  - 每個組合點之後多久「有塞車」。
  - 被點那台車的最低速度。
- **選第2頁用的煞車**：
  - 在「點之後200以內形成塞車，而且通過S」的組合裡，選β·τ最小的。
  - 同分選τ比較短的。
  - 沒有任何組合符合，就照實記錄，交給使用者。

### M5c 調整夠快的對照

- **設定**：用M5b選出的煞車，a ∈ {2.2, 2.5, 3.0}，跑到t0 + 300。
- **通過**：
  - 三個a都沒有塞車。
  - `A(t0 + 300) < 0.01`。

### M5d 分界附近

- **設定**：a ∈ {1.90, 1.94, 1.98, 2.02, 2.05, 2.10}，分別用M5b選出的煞車，和三倍的β（τ不變），跑到t0 + 1500。
- **記錄**：每一組有沒有形成塞車、`A`在t0 + 300、t0 + 1500的值。
- 這一項**只記錄、不判通過**（只檢查S）。
  - 分界附近成長率很小，有限大小的煞車也可能讓線性理論說穩定的一邊出現塞車（介穩態）。
  - 結果決定第5頁怎麼寫「分界」和滑桿的範圍，不預設會看到什麼。

## M6：第3頁的時空圖

- **設定**：用M5b選出的組合，從t0跑到t0 + 600。
  - 畫圖用的取樣間隔`Δt_s = 0.5`。
  - 另外用`Δt_s = 0.05`跑一次比較。
- **通過**：
  - **跨越起點**：
    - 每台車在圖上斷開的次數，剛好等於它繞的圈數（累積位置除以L的整數部分改變的次數）。
    - 沒有任何一段畫出來的線段水平跨超過L/2。
  - **波的方向**：追同一團塞車。
    - 塞車第一次形成時，從速度最低的那台車開始。
    - 之後每個取樣時間，在車速 < 0.1的車裡，找位置（照環道算，前後各L/2以內）離上一次最近的那台，接成不取餘數的軌跡。
    - 這樣可以避免在好幾團塞車之間跳來跳去。
    - 找不到車速 < 0.1的車時，軌跡結束。
    - 軌跡至少要有50時間單位，對它做線性回歸得到波速c。
    - `c < 0`，而且所有車的平均速度 > 0（車往前，波往後）。
  - **取樣**：`Δt_s = 0.5`和`0.05`量到的c差 ≤ 5%。
  - 全程通過S。
- **記錄**：c的值（無因次，不換成km/h）。

## M7：第4頁的擾動傳遞

- **設定**：用M5b選出的煞車，跑兩組：
  - 放大的一組：a = 1
  - 對照組：a = 2.5
- **通過**：
  - a = 1：`A(t0 + 200) > 2·A(t0 + 5)`。
  - a = 2.5：`A(t0 + 200) < 0.5·A(t0 + 5)`。
  - 全程通過S。
- **記錄，不判通過**：
  - 被點那台車後面第1～21台，在`[t0, t0 + 100]`裡的最低速度。
  - 有幾台比前一台低。
  - 第4頁不保證每一台都比前一台低，這一項只是讓逐頁稿知道實際的樣子。

## M8：平滑車規則的探索（第8頁，選配）

這是**探索，不擋核心頁面**。結果好不好都照實記錄。HTML只放「有效」而且「有教學價值」的規則，並寫明這是我們設計的規則，不是Stern的控制器。

### 情境

- N = 22、L = 44、a = 1。
- 先用M4選出的ε讓塞車形成，跑到t = 300。
- 在t = 300把第0台車換成平滑車，跑到t = 1500。
- **比較區間**：[1000, 1500]。

### 規則

先試下面這些，可以再加別的。新加的規則也要先寫進這份檔案、commit，才跑。

| 規則 | 平滑車的加速度 |
|---|---|
| R0（基準） | 不換，照原本的模型 |
| R1 | `a_s·(min(U_avg, V(h)) − v)`。`U_avg`是它自己過去50時間單位的平均速度，`a_s = 1` |
| R2 | 照原本的模型，但加速度限制在±0.05 |
| R3 | `a_s·(min(U, V(h)) − v)`，U是固定的目標速度，`U = V(2) = 0.9640`（均勻車流的速度），`a_s = 1` |

### 指標

在比較區間裡算：
- 所有車、所有時間合在一起的車速標準差
- 最低車速
- 「有塞車」的時間比例
- 平均車速

### 判定

- **有效**：
  - 車速標準差比R0少一半以上。
  - 比較區間裡沒有任何一台車的車速 < 0.1。
  - 全程通過S。
- **有教學價值**：R0在比較區間裡「有塞車」，而那條規則沒有。差別要大到畫面上看得出來。

## M2v2：環長44、a = 1，掃車數

- **設定**：同第1版。L = 44、a = 1，N = 3～60，k=1的小擾動`10^−6·cos(2πn/N)`。
- **每1時間單位記一次**，下面任一個條件成立就停止量測：
  1. k=1的波 > 10^−3（太大，不再是線性）
  2. k=1的波 < 10^−10（快碰到浮點誤差的底）
  3. 其他任何一個波 > 0.1 × k=1的波
     - 「其他的波」是k = 2～⌊N/2⌋。
     - k和N−k是同一對共軛，不重複算；k=1的共軛N−1不算「其他」。
  4. t = 2100
- **有效量測區間**：從t = 100到停止的時間。
  - 區間長度 ≥ 200才算資料足夠。
  - 不足200就標「數值無法判定」，**不能算通過**。
  - 如果在t = 100之前就停止，也是「數值無法判定」。
- **每個N的判定**：
  - 資料足夠，而且理論σ的絕對值 ≥ 10^−8：要同號，而且`|σ_meas − σ| ≤ 2×10^−5 + 0.02|σ|`。
  - 資料足夠，理論σ的絕對值 < 10^−8：只檢查`|σ_meas − σ|`在同樣的容許誤差內，不要求同號。
- **記錄**：每個N的有效量測長度、停止原因、判定結果。
- **M2v2通過**要三件事都成立：
  - 每個N都資料足夠，而且都相符。
  - 在理論σ的絕對值 ≥ 10^−8的N裡，`σ_meas > 0`的剛好是16～39。
  - 全程通過S。
- 有任何N是「數值無法判定」，M2v2就**不算通過**，照實記錄是哪幾個N。

## M5a v2：第2頁點擊之前的均勻車流（展示設計）

使用者選了方案A。讀者點擊之前，均勻車流用**解析解**算：
- `x_n(t) = n·b + V(b)·t`
- `v_n(t) = V(b)`

點擊那一刻，把當下的解析解當成RK4的初始狀態，同時開始煞車，之後才做數值積分。

這是展示設計，**不是**宣稱數值積分可以永遠維持完全均勻。數值積分在t ≈ 436就會因為浮點誤差而不均勻，這是第1次的結果，保留。

測試，全部通過才算M5a v2通過：
1. **點擊之前**：t從0到3000，每0.5取一次，解析解的所有車速都剛好是V(b)，車距都剛好是b。誤差 ≤ 1e−12，只來自浮點運算。
2. **切換的連續性**：在點擊時間t0，RK4的初始狀態跟解析解在t0的位置、速度、時間完全相同。
   - 差 ≤ 1e−12
   - 時間要接續，不能從0重新開始
   - 位置不能瞬移
3. **跟第1次M5b的煞車實驗一致**：t0 = 20，用M5b選出的煞車（β = 0.25、τ = 0.5）。拿第1次的做法（從t = 0就數值積分）來比：
   - 點之後形成塞車的時間差 ≤ 0.1
   - 被點那台的最低速度差 ≤ 1e−6
   - t0 + 100時所有車的位置差 ≤ 1e−6
4. **很晚才點**：t0 = 500，已經超過數值積分自己會亂掉的時間，用同樣的煞車。
   - 點之後200以內形成塞車
   - 點之前完全均勻（同第1點）
   - 全程通過S

## M6v2：第3頁的時空圖

- **設定**：同第1版。用M5b選出的煞車（t0 = 20），跑到t0 + 600；取樣`Δt_s = 0.5`和`0.05`各算一次。
  - 這一項用M5b的原做法（從t = 0就數值積分），跟第1次比較。
  - 點之前的解析解跟它差不到1e−12，見M5a v2的第3點。
- **跨越起點**：同第1版，斷開的次數要等於繞的圈數。
- **塞車團**：
  - 每個取樣時間，把車速 < 0.1的車，依環道上的前後順序分成「相鄰的一群」。第N−1台跟第0台也算相鄰。
- **開始追**：第一次出現至少3台相鄰的車速度 < 0.1時，從那一群開始。
- **追同一團**：
  - 下一個取樣時間，只接受跟上一次那一群至少有一台車相同的群，這樣可以確認是同一團。
  - 符合的群有好幾個時，選相同車最多的。
  - 群的位置：群裡每台車的位置，以上一次的位置為準換算到前後各L/2以內，取平均，接成不取餘數的軌跡。
- **暫時找不到**：
  - 連續5個模型時間單位內，可以接受下一個群跟「最後一次找到的那一群」有相同的車，或位置在最後一次位置的2.0以內（一個平均車距）。
  - 超過5個時間單位都沒有，就算追蹤結束。
  - 不能把已經消失的塞車團，跟另一團硬接起來。
- **資料不足**：軌跡短於50時間單位，標「無法可靠量測」，**不算通過**，也不報波速方向。
- **通過**：
  - 跨越起點0處不一致
  - 軌跡 ≥ 50
  - 波速`c < 0`，而且車的平均速度 > 0
  - 0.5和0.05取樣量到的c差 ≤ 5%
  - 全程通過S

## 修改核心求解器：煞車用整數步數判定

第2版重測發現：煞車的開始用浮點時間比大小，第399步最後一個子步算出來的時間是20.000000000000004，煞車因此提早一個子步生效。

改法：
- 煞車`(車, t0, τ, β)`換算成整數步數：
  - 開始步`k0 = t0 / dt`
  - 步數`m = τ / dt`
  - 兩個都必須是整數（誤差 ≤ 1e−9），不是整數就直接報錯，不默默四捨五入。
- 第`k0`步到第`k0 + m − 1`步（從0開始數）是煞車步。
  - 一個煞車步裡，RK4的四次加速度評估都加上煞車。
  - 不是煞車步，四次都不加。
- 不把RK4子步的時間四捨五入。是不是煞車步，只看「這是第幾個完整步」。
- 時間的算法不變：`t = 步數 × dt`。
- 第2頁讀者任意時間點擊（ClickDemo）：
  - 點擊時間可以是任何實數，不必是dt的倍數。
  - 點擊那一刻用解析解建立新的Ring，內部步數從0開始，煞車從第0步開始、共`m`步。
  - 顯示時間 = 點擊時間 + 內部步數 × dt。
- 不使用煞車的模擬，計算過程跟修改前**逐位元相同**。

## M2的補測：只補N = 20、21

- 原本56個資料足夠、而且相符的N，保留第2版的結果，不重跑。
- N = 20、21：初始擾動改成`10^−7`和`10^−8`各跑一次。
  - 其他全部照M2v2：停止條件（k=1 > 10^−3、k=1 < 10^−10、其他波 > 0.1 × k=1、t = 2100）、有效長度 ≥ 200、容許誤差、物理檢查S。
- **判定規則**：
  - 一個N兩種擾動都有跑，結果都要記錄。
  - 只要有任何一種擾動資料足夠（≥ 200），而且**所有**資料足夠的那幾種都跟理論相符，這個N就算相符。
  - 有任何一種資料足夠卻不符，這個N就算不符。
  - 兩種都不足200，就維持「數值無法判定」。
- **事先知道的風險**（使用者核算的理論成長率）：
  - N = 20：k1約0.03041、k3約0.06787
  - N = 21：k1約0.03075、k3約0.07506
  - 擾動越小，k=1碰到上限越晚，但k=3的數值雜訊相對越大，可能更早碰到10%的門檻。所以結果可能還是不足200。
- **M2的總結**：
  - 58個N裡，資料足夠的每一個都相符，而且理論|σ| ≥ 10^−8、σ_meas > 0的剛好是16～39，才算M2通過。
  - 還有任何N無法判定，M2就是「數值無法判定」。
- 第6頁可以引用解析推導的16～39台，但要分開寫：
  - 理論預測的範圍
  - 模擬實際驗證到的範圍
