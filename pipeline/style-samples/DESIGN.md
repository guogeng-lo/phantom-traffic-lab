# 視覺風格樣本：設計計畫（節點7第一步）

用frontend-design技能的流程：先寫計畫，再拿計畫對照「AI生成網頁的常見特徵」檢查、修正，最後才寫程式。

三套用同一份示範資料（`export_sample_data.py`從Python參考模型算的一次點擊）和同樣的文字，只換設計語言。

## 第一版樣本的問題（使用者叫停前做的那一版）

自己回頭看，第一版踩了很多技能列出的通病：
- B的「PAGE 02」「RING VIEW · 環道」「MODEL TIME」：大寫英文小標、中點串接、等寬字體的小標籤。
- C的「02 — 點一下」：「字 — 片段」的格式；`#111`當黑色。
- A每一塊都是同樣圓角、同樣陰影的白卡片。
- 三套的版面骨架幾乎一樣（左圖右欄），差別主要在配色，不符合「不要只是換底色」。
- 車子在三套裡都是同一種抽象記號，沒有用到交通這個主題本身的東西。

## 共同原則（三套都遵守）

- **主角是圖**：環道和時空圖至少佔版面的六成，文字用來指路，不是用來讀。
- **顏色有固定的意思**（每套用自己的色票，意思一樣）：
  - 慢到幾乎停住（車速低於0.1）：紅色系
  - 你點的那台車、你可以按的東西：每套各有一個「互動色」
  - 塞車波的方向：跟「幾乎停住」同一個顏色系，因為它就是停住的地方在移動
  - 車子前進的方向：中性的墨色
- **來源標示**：【實驗】【模型】【我們的模擬】照原樣出現，括號保留。
- **示範資料要寫明**：車子的位置是Python參考模型事先算好的，不是正式的瀏覽器模擬。
- **模型時間**：寫「模型時間沒有單位，不是秒；動畫已加速」。
- **動態**：只有車流本身在動；沒有入場動畫、沒有懸停特效。尊重`prefers-reduced-motion`（預設暫停，按了才播）。

## A　互動科學館

**主題從哪來**：科學館的互動展台。展台上有一個實體的小環道模型，旁邊一塊說明牌告訴你「按這裡、看那裡」，按鈕是黃色的大按鈕。

| 用途 | 顏色 |
|---|---|
| 展場牆面 | `#EEF2EC` 淡灰綠 |
| 說明牌 | `#FFFFFF` |
| 文字墨色 | `#1F2D27` 深綠墨 |
| 柏油路面 | `#47504C` |
| 互動色（你點的車、按鈕） | `#FFC21A` 展場黃 |
| 幾乎停住 | `#D9412B` |
| 比均勻車流快 | `#2F7FD8` |
| 均勻車流的速度 | `#F2EEE3`（在深色路面上是淺色車） |

- **字體**：標題用圓體（Chiron GoRound TC）800，親切但筆畫粗、遠看清楚；內文Noto Sans TC 400／700。字級：說明文字20、操作步驟24、標題clamp(34–60)。行高1.6。
- **車子**：從上往下看的小汽車（車身＋擋風玻璃），長度照模型比例（0.3個模型長度），所以塞車時一台貼一台、但不重疊。路面畫白色邊線和指示方向的箭頭標線。
- **時空圖**：白底圖表，像展板上的大圖；用「對話框」直接標在圖上：「這台車」「幾乎停住的地方」。
- **控制元件**：大型黃色膠囊按鈕，按下有實體凹陷感（陰影變短），不是懸停效果。
- **版面**：

```
┌ 大標題（左對齊，圓體） ─────────────────────┐
│ ┌──── 環道模型（佔 60%） ────┐ ┌ 說明牌 ────┐ │
│ │                            │ │ 1 點一台車  │ │
│ │                            │ │ 2 看後面的車│ │  ← 真的是先後順序，所以用數字
│ │                            │ │ 3 找停住的地方│
│ └────────────────────────────┘ │ 模型時間 計數器│
│  圖例：車子的顏色是什麼意思     │ [重來] [暫停]  │
│ 來源標示一行　　出處▸           └─────────────┘ │
└──────────────────────────────────────────────┘
```

## B　交通觀測室

**主題從哪來**：夜間從高處觀測車流。夜裡從空中看車，看到的是車燈：**煞車或慢下來的車，尾燈是紅的**。這是交通本身的視覺語言，用它來表示「慢」最直覺。時空圖做成「長時間曝光照片」：車燈拉成光軌，塞住的地方紅光堆在一起。

| 用途 | 顏色 |
|---|---|
| 夜色背景 | `#131D27` 深石板藍（不是近黑色） |
| 路面 | `rgba(255,255,255,.06)` |
| 文字 | `#E4EAF0`，次要`#93A3B3` |
| 車頭燈（前進中的車） | `#F4F8FF` |
| 尾燈（越紅越慢） | `#FF4A3D` |
| 互動色（你點的車、標註） | `#FFB23F` 鈉燈琥珀 |

- **字體**：全部用一套黑體（Chiron Hei HK），數字也用同一套，不用等寬字體。標題700、讀數600大字、說明400。
- **車子**：每台車是一對白色車頭燈＋一對尾燈；尾燈亮度隨車速變慢而變紅。光暈重疊是自然的「燈光堆在一起」，不會像撞車。
- **時空圖**：深色底，用相加混色畫光軌：前進的車是淡淡的白藍光軌，幾乎停住的地方是紅光，越多車停過越亮。右上角放一個同步播放的小環道。
- **控制元件**：底部一條「觀測時間軸」，顯示點擊後經過的模型時間，紅色刻度標出「第一次有車幾乎停住」的時間；播放／暫停是一個圓形按鈕。沒有卡片，資訊直接疊在畫面邊緣。
- **版面**：

```
標題（左上，白字）
┌──────────── 夜間環道（滿版） ────────────┐  ← 讀數直接寫在畫面右側邊緣：
│                                          │     模型時間、最慢的車速、幾乎停住的車數
│                                          │
└──────────────────────────────────────────┘
▶ ───●───────────|紅刻度|─────────────── 時間軸
字幕列：現在發生什麼事（一句）
```

## C　現代資訊圖鑑

**主題從哪來**：百科圖鑑的「圖版」——一張大圖、編號注解、旁邊一欄讀圖說明。中文的圖鑑和書籍傳統可以直排，所以**標題直排**當成這套的招牌（手機改橫排）。

| 用途 | 顏色 |
|---|---|
| 紙面 | `#F7F8FA` 冷白 |
| 墨色 | `#1C2040` 深靛藍（不是近黑色） |
| 幾乎停住 | `#E0313A` |
| 均勻車流的速度 | `#A3ABB8` |
| 比均勻車流快 | `#13849A` 青 |

- **顏色只用來表示車速**，其他資訊都靠形狀：證據種類用框線樣式（實線填滿＝實驗、空心＝模型、斜線網底＝我們的模擬）；你點的車用三角形記號＋編號①。
- **字體**：直排標題Noto Serif TC 900（書籍感），內文和注解Noto Sans TC。大數字用Serif。
- **車子**：環道上是小圓點，每台車外側有一根放射狀的線，**線的長度＝車速**，再畫一圈虛線當「均勻車流的速度」的參考線。塞車的地方，線又短又紅，一眼看得出來。這是把環道直接變成一張資訊圖。
- **時空圖**：細線＋編號注解①②③（這台車／幾乎停住：線接近直直往下／塞車團往後移）。旁邊一欄「讀圖方法」用三個小圖示範三種斜線的意思。
- **控制元件**：方角、粗框線的按鈕；選項用編號清單。
- **版面**：

```
┌──┬──────────────────────────┬──────────────┐
│直│                          │ ① 你點的車    │
│排│     環道圖版（放射線）    │ ② 幾乎停住    │
│標│                          │ ③ 比較快      │
│題│                          │ 模型時間（大字）│
│  │                          │ 按鈕          │
└──┴──────────────────────────┴──────────────┘
讀圖方法（三個小圖）　來源標示　出處
```

## 拿計畫對照常見特徵之後改了什麼

- **B原本想用「黑底＋霓虹青」**：這就是「近黑底配單一亮色」的通病，而且跟交通沒有關係。改成**車燈**：白色車頭燈、紅色尾燈、琥珀色鈉燈當標註色，三個顏色都是夜間道路本來就有的。
- **C原本想用細線分隔、零圓角的報紙排版**：這是「報紙版面」的通病。改成**圖鑑圖版＋直排標題＋放射狀車速線**，用編號注解（注解本來就有對應關係，所以編號有意義）。
- **A原本是一堆同樣的白色圓角卡片**：改成只有一塊「說明牌」，其他東西直接放在牆面上；圓角只用在按鈕（實體按鈕）和環道模型的底座。
- **三套都拿掉**：大寫英文小標、中點串接、等寬字體的小標籤、按鈕後面的「→」。
