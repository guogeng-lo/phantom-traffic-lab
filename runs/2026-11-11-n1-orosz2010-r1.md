## 這次特別要確認的事（使用者提醒）

使用者提醒：不要只看到公式相似，就當作已經驗證了我們的22台車推導，要確認Orosz討論的穩定條件真的對應Bando的模型。確認結果：

1. **是不是同一個模型**：Orosz第4462頁式(3.12)的OV模型取W = 0、延遲全部為0，就是Bando式(1)。Orosz在同一頁明說零延遲的設定就是Bando 1995用的。對應關係是a = 1/T。
2. **車距的定義不同**：Orosz的h扣掉車長、環長是L + Nℓ；Bando不考慮車長。兩邊的均勻車距都是L/N，要對應時取ℓ = 0。
3. **係數**：依Orosz式(5.2)，F = V'/T = aV'，G = W' = 0，H = 1/T = a。
4. **代入後**：(A6)在G = 0時化成V' = a / (2cos²(kπ/N))，跟Bando式(11)代入α_k一樣；Orosz寫明最先不穩定的是k = 1；N趨近無限大時(A8)變成V' < a/2。
5. **適用範圍**：只限沒有延遲。Orosz第4467頁說延遲夠大時，最先不穩定的會變成短的波。

結論：公式對應成立，但「把Orosz的一般公式代入Bando模型」這一步是我們做的，Orosz沒有直接算。所以這一步寫成獨立的推導文件`wiki/derivations/finite-n-threshold.md`，證據卡`ours-finite-n-threshold`的來源改成指向這份文件（原本指向`audition/ovm.py`，那個檔案只有程式，沒有推導過程）。
