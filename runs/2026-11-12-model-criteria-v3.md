## 使用者的決定

1. **M5a選方案(a)：批准修正核心求解器**
   - 煞車的開始和結束改成用整數積分步數判定，不再用浮點時間直接比較。
   - 同一個完整RK4步驟內，四次加速度評估用一致的煞車狀態。β = 0.25、τ = 0.5、dt = 0.05時，要恰好生效10個完整步驟。
   - 不直接把所有RK4子步的時間四捨五入，要正確處理步驟邊界，並保留使用者任意時間點擊時連續的位置、速度和顯示時間。
   - 新增起點、終點、步數和解析解切換的回歸測試。
   - M5a第3項改成跟「修正煞車判定之後的M5b基準」比較，不再要求跟有浮點邊界問題的第1版結果逐字一致。原始結果保留。
   - 修正後重跑M5b、M5c、M5d、M6、M7，以及M5a受影響的小項。
   - 修改涉及共用的RK4運算，要確認不使用煞車的模擬沒有意外變化。
2. **M2選方案(b)：批准補測較小的初始擾動**
   - 不把全部58個N都改成1e−8。原本56個資料足夠、符合標準的N保留結果。
   - 只針對N = 20、21，事先寫好補測方案，測1e−7和1e−8。
   - 使用者核算：
     - N = 20：k1約0.03041、k3約0.06787
     - N = 21：k1約0.03075、k3約0.07506
     - 縮小擾動可能讓其他模態的數值雜訊更早碰到10%的門檻。
   - 保留原本的有效區間長度、模態汙染門檻、成長率誤差和物理檢查，不能看到結果後臨時挑最容易通過的條件。
   - 補測後資料可靠，就加進M2的總結；還是不足，就標數值無法判定，不能偽裝成通過。
   - 第6頁可以引用解析推導的16～39台，但要分開理論預測和模擬驗證的範圍。
3. **M6v2正式接受通過**
   - 車速+0.9632、塞車波速−0.1505，兩種取樣相符，跨越起點0處錯誤。
   - 不再改追蹤規則。但因為要改共用的煞車處理，M6要做一次回歸測試。
4. **紀錄和順序**
   - 先commit第3版標準和這份決策紀錄，再改求解器、補測試、跑回歸。
   - 第1版、第2版的失敗和無法判定紀錄都保留，不能改成PASS。
   - 不要因為探索項目不確定，就擋住其他已經有可靠依據的頁面規劃。
